💾 Want the real thing?

  

    This web demo browses a virtual DOS filesystem for the nostalgia.
    
The real SmartFile 2026 browses your actual files, locally, in your terminal.
  

  

    $ git clone https://github.com/jawnty/smartfile.git

    $ python3 smartfile.py

    $ python3 smartfile.py --gray   # monochrome mode
  

  

    Requires Python 3 and a terminal. No dependencies.
